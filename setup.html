RSVP setup check

Paste the web app URL from Apps Script and this page will send a real test reply, then tell you exactly what happened. Nothing here is linked from the invitation.

  1. Create a Google Sheet, then Extensions → Apps Script.
  2. Paste the contents of google-apps-script/Code.gs and save.
  3. Deploy → New deployment → Web app, with Execute as: Me and Who has access: Anyone.
  4. Copy the URL ending in /exec and paste it below.
